# Уведомление о форке, исходниках и лицензии

`InstallProtection_RU` — неофициальный русский форк Install Protection.

- Основа: полный upstream-исходник `241 / 2.1.68`, commit `5e584196f38568ccfd9a68b4d54a9a1117179010`.
- Оригинальный автор: yijun01 / 永恒之蓝（小淋）.
- Upstream: https://github.com/yijun01/com.install.appinstall.xl
- RU-форк: https://github.com/CaliostRa/InstallProtection_RU
- Основные изменения: русская локализация presentation layer, воспроизводимая Gradle-сборка, CI и безопасная конфигурация подписи.

## Разрешение автора

В ответе владельца upstream от 2 сентября 2026 года автор подтвердил, что:

- загружены полные актуальные исходники, соответствующие APK `241-2.1.68`;
- APK производных форков можно публиковать;
- необходимо сохранить оригинальный `LICENSE`, сведения об авторе, ссылку на upstream и полный исходный код изменений;
- продажа самого приложения и коммерческое использование запрещены;
- добровольные пожертвования допустимы;
- русскую локализацию следует поддерживать отдельным форком, а не upstream PR.

Источник: https://github.com/yijun01/com.install.appinstall.xl/issues/28#issuecomment-5502698754

## Условия распространения

Оригинальный `LICENSE` сохранён дословно. Его вводная часть содержит GPL-3.0 и дополнительные некоммерческие ограничения upstream. Поэтому форк не описывает лицензию как «чистую GPL-3.0» и не удаляет дополнительные условия автора.

При публикации APK должны одновременно быть доступны:

1. точный публичный commit/tag исходного кода сборки;
2. полный исходный код RU-изменений и скрипты сборки;
3. неизменённый upstream `LICENSE`;
4. сведения об оригинальном авторе и ссылка на upstream;
5. явная пометка, что это неофициальный русский форк.

APK нельзя продавать или использовать как платный продукт. Этот репозиторий не добавляет платных функций и не содержит ссылки на пожертвования. Само разрешение автора на добровольные пожертвования не отменяет остальные ограничения upstream.

## Соответствие исходников и бинарника

Ветка форка собирает Android-модуль непосредственно из `APP/installCheck/app`. Version metadata сохранена как upstream: `versionCode 241`, `versionName 2.1.68`. Package name, Xposed entry point и provider не изменены.

Тег upstream `241-2.1.68` был создан до финальной загрузки исходных файлов, поэтому точной базой исходника является более поздний commit `5e584196f38568ccfd9a68b4d54a9a1117179010` в `upstream/main`. Эта особенность зафиксирована в README, чтобы база сборки была однозначной.

## Изменения RU-форка

- Android resources `values`/`values-ru` для локализуемых метаданных и статического UI;
- locale-gated перевод динамического Java UI и показываемых логов только на presentation-sinks;
- русский каталог переводов и аудит непокрытых Han-строк;
- короткие строки маленького overlay;
- исправление двух дублирующихся Java `case`, мешавших компиляции исходника;
- Gradle Wrapper, сборка debug/unsigned release и GitHub Actions;
- optional signing только через внешние переменные/Secrets — приватный ключ в репозиторий не добавляется.

Hook-алгоритмы PackageManager, сети/VPN, `/proc/net`, NetworkInterface, anti-Xposed, SELinux, Developer Options/ADB, package detection и LSPatch не перерабатывались.
