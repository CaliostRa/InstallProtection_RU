# Уведомление о форке и лицензии

InstallProtectionR является неофициальной русской модификацией Install Protection.

- Основа: Install Protection `2.1.60 (234)`.
- Оригинальный автор: yijun01 / 永恒之蓝（小淋）.
- Upstream: https://github.com/yijun01/com.install.appinstall.xl
- Изменение: русская локализация, воспроизводимая сборка и CI.
- Hook-алгоритмы официального APK не переписывались.

Оригинальный `LICENSE` сохранён без изменений. Он одновременно называет GPL-3.0 и содержит запрет коммерческого использования. [GNU GPLv3](https://www.gnu.org/licenses/gpl-3.0.html) разрешает коммерческое распространение и считает иные непредусмотренные ограничения «дальнейшими ограничениями»; [FAQ GNU](https://www.gnu.org/licenses/gpl-faq.html#DoesTheGPLAllowMoney) отдельно подтверждает возможность взимать плату. Поэтому формулировки upstream могут конфликтовать. Форк не добавляет новых лицензионных ограничений. Для публичного или коммерческого распространения рекомендуется получить юридическую консультацию или уточнение у правообладателя.

Кроме того, опубликованный Gradle-исходник в теге `234-2.1.60` объявляет версию `2.0.88` и не соответствует официальному APK `2.1.60`. Этот форк публикует полный исходный код собственных изменений и воспроизводимый способ их применения, но не может заменить отсутствующий соответствующий исходный код upstream DEX. Поэтому полное выполнение требования GPLv3 о Corresponding Source для распространения модифицированного APK нельзя независимо подтвердить, пока upstream не опубликует совпадающий исходник или правообладатель не уточнит условия.

По этой причине GitHub Actions не создаёт публичные GitHub Releases с APK автоматически. Workflow artifact предназначен для проверки воспроизводимости сборки; перед публичным распространением бинарника необходимо отдельно подтвердить права и выполнение требований к Corresponding Source.

Исходный код изменений форка находится в `localization/`, `tools/`, Gradle-файлах и `.github/workflows/`.
