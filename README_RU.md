# InstallProtection_RU — русский форк Install Protection

Это неофициальный русский форк Android/Xposed-модуля [Install Protection](https://github.com/yijun01/com.install.appinstall.xl). В форке переведены интерфейс, диалоги, плавающее окно и пользовательские журналы; алгоритмы hooks и package name `com.install.appinstall.xl` сохранены. Имя форка — `InstallProtection_RU`, отображаемое имя приложения — `Install Protection RU`.

Проект не является форком самого LSPatch и не аффилирован с его разработчиками: LSPatch здесь только один из поддерживаемых способов запуска модуля.

База форка: официальный релиз `2.1.60`, build `234`, tag `234-2.1.60`, commit `3e930ddc1bc601d88255cd9f214a4b9a35e97327`.

Оригинальный README на китайском: [README.md релиза 2.1.60](https://github.com/yijun01/com.install.appinstall.xl/blob/234-2.1.60/README.md).

## Описание оригинального проекта на русском

Install Protection использует Android/Xposed hooks, чтобы перехватывать способы проверки установленных приложений: запросы `PackageManager`, обращения к файлам и каталогам, команды `pm`/`dumpsys`, сетевые проверки и другие признаки. Для выбранных package ID модуль возвращает заданный режим — «установлено» или «не установлено» — и не раскрывает реальный список приложений устройства.

Типичный сценарий: приложение A требует установить приложение B и иначе ограничивает работу или закрывается. Модуль позволяет сообщить приложению A, что B уже установлено, не устанавливая B на устройство.

Основные возможности оригинала:

- два режима подмены статуса: считать обнаруженный пакет установленным или неустановленным;
- автоматический перехват запросов и ручное добавление package ID;
- проверки через `PackageManager`, файловую систему, команды, плагины и сеть;
- блокировка типовых и усиленных способов принудительного выхода;
- защита разрешений, включая запросы `QUERY_ALL_PACKAGES`;
- контроль запуска сторонних приложений и ссылок: реальный запуск, подмена запуска или отмена;
- отдельная конфигурация для каждого целевого приложения;
- импорт и экспорт конфигурации;
- плавающее окно для смены режима, управления перехватом и списком пакетов;
- работа через LSPosed на root-устройствах и через LSPatch без root.

Ограничения и предупреждения оригинала:

- не включайте модуль для системных приложений: это может вызвать сбои системы;
- приложения с упаковщиком, проверкой подписи или собственной защитой могут блокировать Xposed hooks;
- некоторые нестандартные проверки установки могут перехватываться не полностью;
- конфигурация хранится в данных целевого приложения и удаляется вместе с его данными;
- автоматически обнаруженные package ID могут не входить в экспорт конфигурации;
- оригинальный автор разрешает использование только для личного изучения и тестирования; лицензионная неоднозначность подробно описана в [NOTICE_RU.md](NOTICE_RU.md).

## Отличия от оригинала

- русский интерфейс при системной локали `ru`/`ru-RU`;
- русский текст диалогов, плавающего окна, настроек и журналов;
- вручную вычитанный каталог из 1208 upstream-строк и двух контекстных сокращений для overlay;
- короткие подписи в плавающем окне;
- исходный китайский интерфейс для остальных локалей;
- исходные package ID, имена Android API, методы, пути и hook-поведение сохранены;
- добавлена воспроизводимая unsigned-сборка и GitHub Actions.

NetCloak в проект не включён. Install Protection RU и NetCloak остаются отдельными Xposed-модулями.

## Важное примечание об исходниках 2.1.x

В теге `234-2.1.60` открытый Gradle-проект `APP/installCheck` всё ещё соответствует старому `2.0.88` и не содержит классы текущих функций VPN/proxy, скрытия следов и realtime logs. Актуальный код `2.1.60` опубликован upstream только в release APK.

Поэтому сборка RU-форка:

1. загружает официальный APK `2.1.60 (234)`;
2. проверяет его закреплённый SHA256;
3. оставляет декодер строк и smali-классы DEX hooks без изменений;
4. добавляет locale-gated перевод только перед 18 штатными Android UI-вызовами (`TextView`, `AlertDialog`, `Toast`, `Html` и списки) и добавляет `values-ru`;
5. собирает unsigned APK.

Служебные строки `Intent`, `PackageManager`, JSON, файловой системы, сети и Xposed не проходят через переводчик. Это позволяет сохранить функции и LSPatch/LSPosed entry points версии 2.1.60 без переноса старой hook-логики из 2.0.88.

## Установка через LSPosed

1. Установите APK `InstallProtection_RU-2.1.60-release-unsigned.apk`. Для unsigned APK потребуется подписать файл своим ключом перед установкой.
2. Откройте LSPosed → «Модули» → `Install Protection RU`.
3. Включите модуль.
4. Отметьте только нужные целевые приложения. Не выбирайте системные приложения.
5. Полностью остановите и снова запустите целевое приложение.

## LSPatch без root

Патчить нужно приложение, которое выполняет нежелательную проверку установленных пакетов. Не патчите VPN-клиент, если проверку выполняет другое приложение.

```text
LSPatch
→ выбрать APK целевого приложения
→ Embedded mode
→ выбрать Install Protection RU
→ Patch
→ установить пропатченный APK
```

Если приложение проверяет подпись или защищено упаковщиком, патч может не установиться либо hooks не загрузятся. Перед заменой установленного приложения сохраните его данные и убедитесь, что знаете способ возврата к оригинальному APK.

## Использование

- Нажатие на плавающее окно открывает текущий режим и основные настройки.
- Долгое нажатие открывает скрытие окна и очистку конфигурации.
- Двойное нажатие открывает добавление package ID вручную.
- Перетаскивание меняет положение окна.
- Временно скрытое окно возвращается двойным нажатием клавиши громкости или после перезапуска приложения.
- Долговременно скрытое окно возвращается тройным нажатием `Громкость +`/`Громкость -`.

Короткий статус окна:

```text
Защита: есть [перехват]
Защита: нет [перехват]
```

Основные разделы:

- «Основные функции перехвата» — PackageManager, файлы и обходные проверки;
- «Управление пакетами» — обнаруженные package ID и режим ответа;
- «Дополнительные настройки» — запуск, разрешения, выход и кнопка «Назад»;
- «VPN и прокси» — только исходные функции скрытия сети;
- «Скрытие следов» — Xposed/LSPatch, Root, ADB и Developer Options;
- «Журнал в реальном времени» — пользовательские сообщения модуля, технические API остаются на английском.

## Импорт и экспорт

Импорт/экспорт работает с конфигурацией целевого приложения. Автоматически обнаруженные package ID могут не входить в экспорт upstream-версии; перед очисткой проверьте содержимое списка.

## Сборка

Требования: JDK 17, Python 3 и доступ к GitHub Releases.

```bash
export JAVA_HOME=/path/to/jdk-17
./gradlew clean
./gradlew assembleDebug
./gradlew assembleRelease
```

Результаты:

```text
build/outputs/apk/debug/InstallProtection_RU-2.1.60-debug-unsigned.apk
build/outputs/apk/release/InstallProtection_RU-2.1.60-release-unsigned.apk
```

Сборка загружает только официальный upstream APK и Apktool по HTTPS, после чего проверяет оба SHA256. Приватные ключи в репозитории отсутствуют.

CI сохраняет unsigned APK как проверочный workflow artifact, но намеренно не публикует его автоматически в GitHub Releases. Публичный бинарный релиз следует включать только после того, как правообладатель уточнит условия лицензии и предоставит соответствующий исходный код APK 2.1.60; подробности приведены в [NOTICE_RU.md](NOTICE_RU.md).

## Обновление от upstream

```bash
git remote add upstream https://github.com/yijun01/com.install.appinstall.xl.git
git fetch upstream --tags
```

Для нового релиза обновите URL, versionCode/versionName и SHA256 в `tools/build_localized_apk.py`, затем выполните аудит entry points и обновите `localization/ru-strings.json`. Нельзя переносить словарь на новый APK без проверки: upstream может изменить обфускацию и hook-классы.
